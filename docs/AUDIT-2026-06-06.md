# Sigma audit notes - 2026-06-06

Scope: Stylus Core, Solidity Vault/Strategist/oracle, TypeScript Pilot, Next.js dashboard, and the public Robinhood Chain testnet deployment.

## Fixed in source

- Critical: liquidation previously allowed arbitrary collateral seizure with zero repayment.
- High: Strategist over-repayment could strand excess user USDC in the contract.
- High: zero or understated VaR had no independent LTV backstop.
- Medium: risk parameters, correlations, asset decimals, and asset count were unconstrained.
- Medium: Chainlink-compatible reads did not reject stale or incomplete rounds.
- Medium: the model prompt requested one action but the tool layer did not enforce it.
- Medium: the dashboard scanned only the latest 50,000 blocks and hid the real action receipt.
- Medium: mobile portfolio and decision-log tables were not readable.
- Low: the site lacked a main landmark and favicon.

## Still open

- Redeploy the Solidity contracts and update all addresses. The current public contracts contain the pre-fix liquidation logic.
- Replace owner-seeded prices and illustrative risk inputs with monitored data sources.
- Add lender accounting, interest, reserves, and bad-debt handling before describing Sigma as a lending market.
- Put owner powers behind a multisig and timelock.
- Add invariant/fuzz tests, independent review, and a reproducible Stylus-versus-Solidity benchmark.
- Host or schedule the Pilot and expose policy/onboarding flows in the web application.

This is an engineering review, not a professional security-audit certification.
