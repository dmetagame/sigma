# Sigma audit notes - 2026-06-06

Scope: Stylus Core, Solidity Vault/Strategist/oracle, TypeScript Pilot, Next.js dashboard, and the public Robinhood Chain testnet deployment.

## Fixed in source

- Critical: liquidation previously allowed arbitrary collateral seizure with zero repayment.
- High: Strategist over-repayment could strand excess user USDC in the contract.
- High: zero or understated VaR had no independent LTV backstop.
- Medium: risk parameters, correlations, asset decimals, and asset count were unconstrained.
- Medium: Chainlink-compatible reads did not reject stale or incomplete rounds.
- Medium: the model prompt requested one action but the tool layer did not enforce it.
- Medium: the dashboard scanned only the latest 50,000 blocks and hid the real action receipt.
- Medium: mobile portfolio and decision-log tables were not readable.
- Low: the site lacked a main landmark and favicon.

## Follow-up completed on 2026-06-07

- Replaced the active seeded adapter with a timestamped reporter adapter fed only after Pyth/RedStone agreement checks.
- Added Vault fuzz properties, blocking Slither analysis, dependency automation, and a reproducible security suite.
- Deployed a behavior-matched Solidity core and measured the same five-asset vector against Stylus.
- Added scheduled GitHub Actions for oracle updates and defensive Pilot guardian checks.
- Replaced scheduled leverage-changing AI ticks with a deterministic repay-only guardian.
- Migrated to a Strategist where cooldown and pre-existing policy violations cannot block repayment.

## Follow-up completed on 2026-06-08

- Exposed wallet-driven deposit, withdrawal, borrow, repayment, and Pilot policy controls in the production web application.
- Made multi-transaction Pilot setup fail closed by activating the policy only after allowance and executor permissions are ready.
- Added complete Pilot revocation for policy state, Vault executor access, and USDC repayment allowance.

## Still open

- Replace the centralized testnet reporter with on-chain verified feeds; volatility and correlation inputs are still illustrative.
- Add lender accounting, interest, reserves, and bad-debt handling before describing Sigma as a lending market.
- Put owner powers behind a multisig and timelock.
- Obtain an independent professional Solidity and Stylus audit of the exact release commit and deployed bytecode.

This is an engineering review, not a professional security-audit certification.

## Deployment follow-up

The hardened Vault and Strategist were deployed on 2026-06-07, followed by the live cross-checked Oracle and Solidity benchmark reference. See `DEPLOYMENT-2026-06-07.md` for addresses and transaction evidence. Legacy contracts remain on-chain but are no longer referenced by the application.
